# Koma UI

**The UI Kit for Intelligent Applications**

A collection of beautifully crafted AI components designed to handle uncertainty, streaming, and complex interactions. Built to be copied, customized, and extended. Open Source. Open Code.

Koma UI is built on top of [shadcn/ui](https://ui.shadcn.com/) and provides ready-to-use blocks for modern, AI-driven applications.

## Quick Start

Before using Koma UI components, ensure you have `shadcn/ui` installed and configured in your project. If you haven't set it up yet, follow the [official shadcn/ui installation guide](https://ui.shadcn.com/docs/installation).

## Adding Components to Your Project

You can add any Koma UI component to your project using the shadcn CLI. Just point the CLI to the component's registry URL.

For example, to install the `thinking-loader` component, run one of the following commands based on your package manager:

**npm:**
```bash
npx shadcn@latest add https://komaui.iamkunal.in/r/thinking-loader.json
```

**bun:**
```bash
bunx --bun shadcn@latest add https://komaui.iamkunal.in/r/thinking-loader.json
```

**pnpm:**
```bash
pnpm dlx shadcn@latest add https://komaui.iamkunal.in/r/thinking-loader.json
```

**yarn:**
```bash
yarn dlx shadcn@latest add https://komaui.iamkunal.in/r/thinking-loader.json
```

The CLI will automatically install the necessary dependencies and place the component in your project's components directory.
